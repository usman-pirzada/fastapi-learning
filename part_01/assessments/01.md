## Question 1

**What is the default URL suffix for accessing API documentation provided by FastAPI via Swagger UI?**

- ○ `/apidoc`
- ○ `/openapi`
- ○ `/swagger`
- ✅ `/docs`

> **Correct!** The Swagger UI documentation is accessed at `/docs`.

## Question 2

**What endpoint suffix is typically used to access custom documentation that uses ReDoc with FastAPI?**

- ○ `/api-docs`
- ○ `/custom-docs`
- ○ `/doc`
- ✅ `/redoc`

> **Correct!** The ReDoc interactive documentation is accessed through `/redoc`.

**Which tool is primarily used for managing Python packages and dependencies in a project?**

- ○ `npm`

- ○ `composer`

## Question 4

**Which Python command is used to create a virtual environment specifically for a new project?**

- ○ `python createenv myenv`
- ○ `venv install myenv`
- ○ `setup venv myenv`
- ✅ `python -m venv myenv`

> **Correct!** This command uses the `venv` module to create a virtual environment named `myenv`.

- ○ `install fastapi extras`
